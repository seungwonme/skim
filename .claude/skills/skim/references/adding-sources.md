# 새 소스 추가

사용자가 링크를 주며 "이것도 수집해줘"라고 할 때의 절차. 판정은 추측이 아니라 `skim source probe`의 실측으로 한다.

## 목차

- 절차
- 등급 읽는 법
- 경고 읽는 법
- scrape로 내려갈지 판단
- 함정

## 절차

1. `uv run skim source probe <url>` — 피드 유무와 추출 등급을 관측한다. 아무것도 저장하지 않는다.
2. 출력의 등급과 경고를 사용자에게 그대로 보여주고, 등록할지 확인받는다.
3. `uv run skim source add <url> --platform blogs` — 진단 후 `tracked_sources`에 등록한다.
4. `uv run skim crawl blogs --days 7` — 실제로 글이 들어오는지 확인한다. 0건이면 등록만 되고 수집은 안 되는 상태다.
5. `uv run skim source list --emit markdown > docs/SOURCES.md` 로 인벤토리를 갱신하고 함께 커밋한다.

소스 목록의 정본은 DB의 `tracked_sources`라 저장소 diff에 안 남는다. 5번을 빠뜨리면 "언제 무슨 소스를 추가했는지"가 사라진다.

## 등급 읽는 법

등급은 사람이 선언하는 값이 아니라 probe가 관측한 값이다. 위쪽일수록 싸고 안정적이다.

| 등급 | 뜻 | 판단 |
|---|---|---|
| `rss` | 피드가 본문까지 실어 보낸다 | 최선. 추출기를 안 거쳐 실패 지점이 없다 |
| `rss+enrich` | 피드는 링크만, HTTP로 본문 추출됨 | 기본값. 대부분 여기 |
| `rss+render` | playwright 렌더가 필요하다 | 받아도 되지만 느리고, 타이밍에 따라 본문이 빌 수 있다 |
| `scrape` | 피드가 없다 | 전용 인덱스 파서를 직접 만들어야 한다 |

## 경고 읽는 법

- **백필 제한** — 피드가 최근 N건만 준다. 과거 글 수집이 불가능하다는 뜻이지 등록을 막을 이유는 아니다.
- **발행일 없는 항목** — `since` 필터가 날짜 없는 항목을 조용히 버린다. 그 수만큼 영영 안 들어온다.
- **author 없음** — 소스명으로 대체되니 동작에는 문제없다.
- **본문 빈약** — 내비게이션만 긁혔을 수 있다. 소스가 원래 짧은 형식(팟캐스트, 제품 목록)이면 정상이니 샘플 URL을 직접 열어 확인한다.
- **playwright 렌더 필요** — 등급 `rss+render`와 같은 신호다. 이 소스는 앞으로도 간헐적으로 본문이 빌 수 있다.

## scrape로 내려갈지 판단

`skim source add`는 `scrape` 등급이면 등록을 거부한다. 전용 크롤러를 만드는 건 유지비가 계속 드는 결정이라 자동으로 넘기지 않는다.

먼저 확인할 것:

- 피드가 정말 없는지 — 사이트 홈이 아니라 **글 목록 페이지 URL**로 다시 probe한다. 경로 스코프 후보(`{경로}/rss`)를 그 경로 기준으로 다시 훑는다.
- 이미 있는 소스와 겹치지 않는지 — 회사 블로그는 한 도메인에 카테고리별 피드가 따로 있는 경우가 있다.

그래도 없으면 사용자에게 "전용 파서가 필요하다"고 알리고, 만들 값어치가 있는지 물은 뒤 진행한다. 기록만 남기려면 `--force`.

## 함정

- **루트 피드가 항상 최선은 아니다** — `{경로}/feed`가 루트 `/feed/`보다 글을 더 담는 경우가 있다. probe는 경로 스코프를 먼저 시도하니 그 결과를 신뢰한다.
- **등록했는데 수집이 안 되면 `feed_url`을 의심한다** — 데스크톱 앱의 소스 UI는 YouTube 필드만 채워서 `feed_url`이 빈다. 크롤러가 그 행을 건너뛰며 이름을 찍어준다.
- **계정이 소유하는 플랫폼은 등록하지 않는다** — reddit, threads, x, linkedin은 구독 목록이 플랫폼 계정에 있다. 레지스트리에 넣으면 실제와 어긋난 목록이 된다.
- **피드가 죽으면 등급이 `scrape`로 떨어진다** — `uv run skim source refresh --all`이 강등을 알린다. 주기적으로 돌려 죽은 소스를 찾는다.
